# Todo List Web App  
⭐ JavaScript | HTML | CSS

This is a simple Todo List Web Application built as part of a coding exercise to practice DOM manipulation and interactive UI.

🔗 **Live Demo:** https://randymulliya17.github.io/CodingCamp-19Jan26-RandyTriMulliya/  
📁 **Repository:** https://github.com/randymulliya17/CodingCamp-19Jan26-RandyTriMulliya

---

## 📌 Features

The Todo List Web App includes the following features:

✔ Add new task  
✔ Mark task as completed  
✔ Delete individual task  
✔ Delete all tasks  
✔ Filter tasks (All, Active, Completed)  
✔ Responsive layout for desktop & mobile  

---

## 🛠 Technologies Used

- **HTML** — Structure  
- **CSS** — Styling & layout  
- **JavaScript** — Logic & DOM Manipulation  

---

## 🚀 How It Works

1. Type a task name in the input field  
2. Click the **Add** button to save a task  
3. Use filter buttons to view specific tasks  
4. Mark tasks as completed or delete them  
5. Use **Delete All** to clear the list
